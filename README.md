# Turnleft fan page #1

## Getting Started

1. `nvm use`
2. `npm install`
3. `npm start`

The local dev server runs at `http://127.0.0.1:8001` by default. To use a
different local port for one run:

```sh
PORT=8010 npm start
```

To preview the built site locally, run `npm run serve`; it defaults to
`http://127.0.0.1:9001`.

## Build and deploy

run `npm run build`, push changes to master branch
